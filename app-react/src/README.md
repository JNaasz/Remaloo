File Structure Reference:

src/
├── assets/         # Static assets like images, fonts, icons, etc.
├── components/     # Reusable UI components (buttons, inputs, etc.)
├── features/       # Feature-specific components and logic
├── layouts/        # Layout components (header, footer, sidebars)
├── pages/          # Page-level components (e.g., Home, About, etc.)
├── hooks/          # Custom hooks
├── services/       # API calls or external services
├── context/        # React Context for global state management
├── utils/          # Utility functions or helpers
├── styles/         # Global and shared CSS/SCSS files
├── App.tsx         # Main application component
├── index.tsx       # Entry point of the React app
└── theme/          # Material-UI or custom theme files
